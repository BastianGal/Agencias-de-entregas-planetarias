#  Agencia de Entregas Planetarias (AEP)
Plataforma web de logística y transporte especial para envíos planetarios ultrarrápidos y de emergencia.
##  Descripción del Proyecto
 **Agencia de Entregas Planetarias (AEP)** es una solución tecnológica diseñada para resolver los retrasos críticos en envíos de suministros médicos, repuestos y cargas prioritarias (reduciendo tiempos que antes tardaban semanas). El sistema permite cotizar rutas orbitales, gestionar usuarios y rastrear entregas

##  Objetivos del Sistema
* **OBJ-01:** Permitir la cotización y solicitud de envíos
* **OBJ-02:** Rastrear entregas en tiempo real mediante mapas interactivos
* **OBJ-03:** Ofrecer un catálogo interactivo de cápsulas de entrega según peso y tipo de carga
* **OBJ-04:** Calculra tiempos estimados de llegada basados en el destino
##  Perfiles de Usuario
1. **Clientes de Emergencia (U-01):** Solicitan entregas prioritarias de insumos críticos de forma rápida.
2. **Operadores de Vuelo / Logística (U-02):** Monitorean la flota, validan rutas y controlan los estados de envío en tiempo real.
3. **Visitantes Generales (U-03):** Exploran servicios de transporte especial, tarifas base y cobertura del sistema.
## Requisitos Funcionales Principales (RF)
* **RF-01 & RF-02:** Visualización y búsqueda avanzada en el el catálogo de servicios de envío.
* **RF-03:** Clasificación de cargas especiales (ejemplo: categoría "frágil").
* **RF-04:** Calculadora automática de tarifas y tiempos según la selección del usuario.
* **RF-05:** Sistema de autenticación con diferenciación de cuentas (Clientes y Empresas).
* **RF-09 & RF-10:** Rastreo en tiempo real y panel de control para operadores (aprobar, cambiar o cancelar envíos).
